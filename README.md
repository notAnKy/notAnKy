## About me

I'm studying software engineering at **TEK-UP University**, specializing in **Data Science & Artificial Intelligence**. I previously earned an applied bachelor's degree in **Information Systems Development** from **ISET Mahdia**.

I enjoy building projects from the first idea through to a working application: designing the interface, implementing the backend, connecting the data, and making the result usable. My work spans real-time collaboration, AI video analysis, and playable games.

- **AI & computer vision:** object detection, license plate detection, video analysis, and retrieval-augmented generation.
- **Web development:** full-stack applications with authentication, databases, and real-time features.
- **Game development:** gameplay systems, progression, co-op prototypes, and interactive 3D experiences.

## Beyond the dashboard

I also build interactive experiences: a **drivable Three.js portfolio world** with seven districts, project interactions, a map, and mobile controls, plus a **Unity survival prototype** with resource gathering, inventory, crafting, and save/load systems.

I'm interested in game design as well as implementation. My **[VALORANT agent-selection case study](https://agent-select-case-study.vercel.app)** explores what happens when players want the same agent, compares possible solutions, and proposes a preference fallback with fairness rules and a playtest plan.
